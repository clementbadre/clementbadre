# Clément Badré

MSc Financial Engineering student at EPFL, interested in quantitative
research, trading and data-driven financial modelling.

My work focuses on:
- Quantitative finance and derivatives
- Machine learning for financial markets
- Time-series analysis
- Statistical modelling
- Python

## Selected Projects

### Earnings Call Sentiment & Stock Returns
Machine-learning models combining earnings-call sentiment and quantitative
factors to predict cross-sectional stock returns.

### Information Diffusion Across NASDAQ Stocks
Analysis of lead-lag relationships using cross-correlation and
Granger causality.

### Merton Jump-Diffusion & Implied Volatility
Calibration and analysis of volatility smiles generated by the
Merton jump-diffusion model.
