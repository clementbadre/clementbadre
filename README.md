# Clément Badré

MSc Financial Engineering student at EPFL, interested in quantitative research,
systematic trading and machine learning applied to financial markets.

**Python · Machine Learning · Time Series · Derivatives · Quantitative Finance**

## Selected Projects

### Earnings-Call Sentiment for Return Prediction

Machine-learning pipeline combining FinBERT sentiment from earnings-call
transcripts with quantitative factors to predict cross-sectional stock returns.

Models include XGBoost, MLP, LSTM and Transformer architectures, with
out-of-sample evaluation and long-short portfolio backtesting.

[View project](/clementbadre/earnings-call-return-prediction)

### The Pulse of the Market — Who Sets the Rhythm?

EPFL Applied Data Analysis team project investigating leadership and information
diffusion across NASDAQ stocks using cross-correlation, Granger causality and
portfolio analysis.

My contributions included performance metrics, company hierarchization,
survivorship-bias analysis, sector-size effects, interactive visualizations
and data storytelling.

[View code](/epfl-ada/ada-2025-project-theoutliers)
